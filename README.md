# Himadri Chatterjee | Portfolio & Consulting Website

A modern, high-performance, and visually premium portfolio website highlighting Himadri Chatterjee's 25+ years of functional expertise in Operational Excellence, Lean Six Sigma, and Business Transformation. This site also acts as a digital landing page and service offering for **Opex Consulting Group**.

## Features

- **Premium Design Aesthetic:** Styled with a sleek, corporate dark-navy theme, elegant typography (Outfit & Inter), and subtle gold/teal color accents.
- **Dynamic Interactions:** Features soft CSS keyframe glass-morphism effects, hover behaviors along the timeline, and lazy scroll transitions for a luxurious feel.
- **Fully Responsive Structure:** Implements Flexbox, CSS Grids, and targeted fluid typography to guarantee pristine layouts across 4K desktop screens down to small mobile phones.
- **Functional Contact Pipeline:** A completely serverless Contact Form powered by FormSubmit. Submissions are instantly routed to the configured email without requiring any backend database.
- **Interactive Document Links:** The certifications section contains direct document-viewer buttons that gracefully open matching PDF certificates located locally within the site architecture.

## Tech Stack

This project is constructed using a robust, dependency-free core stack:
- **Structure:** HTML5
- **Styling:** Vanilla CSS3 (Custom Properties & Tokens)
- **Interactivity:** Vanilla JavaScript (ES6)
- **Icons & Fonts:** BoxIcons / Google Fonts

## How to View

Because this is a beautifully light-weight static site with no heavy node frameworks, there are no build steps to view it!

1. Simply navigate to the root folder on your computer.
2. Double-click the `index.html` file. 
3. The interactive site will automatically open and run smoothly inside your default web browser (Chrome, Edge, Safari, etc.).
